# divergence and is skipped. See LinkedEvalScriptedTests.
#
# Format: <test-file-name>: <reason>
#
# Every entry below is category (a) dynamic-eval: the transcript exercises
# eval(...) / evalSafe(...) / embedRepl(...), which the linked image cannot serve
# (a linked line needs a synchronous relink + import, which is impossible — RECON3
# HIGH risk). The driver refuses it fast ("dynamic eval(...) is not supported in
# linked REPL mode"); evalSafe(...) catches that refusal and returns a Failure, so
# an evalSafe line succeeds with the fallback value instead. Every such transcript's
# NORMAL setup lines replay byte-identically in linked mode first — only the eval
# line diverges (the harness short-circuits at that first mismatch).
#
# Not represented here (categories with zero occurrences in this suite): (b)
# structural/reflective selection, (c) stack-frame formatting, (d) falsely-excluded
# image members, (e) unexplained. The one non-eval divergence found — the
# ExtraLibsTests shadow-order case — was FIXED (LinkedRunner.buildBase now dedups
# duplicate .sjsir first-wins), not skipped.
